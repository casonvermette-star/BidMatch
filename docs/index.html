AI-assisted construction procurement, from bid intake to leveled subcontractor shortlist.

BidMatch AI is a full-stack Node.js prototype for general contractors. It organizes projects, extracts scopes, ranks subcontractors, applies qualification gates, manages outreach, and levels bids.

CAPABILITIES

What the project demonstrates

Client workspace

Project intake, document uploads, scope editing, contractor matching, bid lists, outreach tracking, and leveling.

Qualification engine

Hard eligibility gates are separated from fit scoring for licensing, insurance, bonding, package capacity, safety, workload, and market fit.

Platform admin

Cross-workspace operational dashboard with its own isolated login for organizations, users, subscriptions, integrations, and audit activity.

Production path

Optional Supabase persistence, Resend email delivery, Stripe subscriptions, Docker deployment, backups, exports, and role-based access.
