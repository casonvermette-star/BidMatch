## BidMatch AI — Construction Procurement SaaS Prototype

Built a full-stack, multi-tenant construction procurement platform that helps general contractors move from project intake and bid documents to qualified subcontractor recommendations and leveled bids.

The project includes a client portal for project/scoping/bidding workflows and a **separate platform-owner admin application** with isolated authentication for cross-workspace metrics, users, subscriptions, system health, and audit activity.

Core engineering work includes deterministic qualification gates, contractor fit scoring, editable scopes, bid leveling, organization-scoped authorization, team roles, CSV contractor import, file upload/storage hooks, background outreach jobs, exports/backups, and optional OpenAI, Supabase, Resend, and Stripe integrations.

Stack: Node.js, JavaScript, HTML/CSS, REST APIs, Docker, GitHub Actions, optional Supabase/Stripe/Resend/OpenAI.

Portfolio note: contractor identities and operational metrics bundled with the demo are fictional test data.
